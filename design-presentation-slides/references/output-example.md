# Outputs example

An example `Outputs` section for a draft that has not been rendered. Adapt the headings to the deliverables. A small text repair needs only the replacement wording and its limits.

```markdown
## Outputs

### Files

- Editable draft: [deck-v2.pptx](deck-v2.pptx)
- Presenter notes: [notes.md](notes.md)
- Reading export: [reading-v2.pdf](reading-v2.pdf)

### Checks

Revision: draft 2.

| Check | Result |
| --- | --- |
| Arithmetic against the [timing figures](sources/timing-example.md) | Passes: 90 to 72 minutes is a 20% reduction. |
| “Illustrative figures” label on the comparison slide | Present. |
| Rendered slides, reveal states and reading export | Not checked. |
| Native editability and recipient access to notes | Not checked. |

Status: unverified draft.

### Continuation

Render and inspect the slides and exports at the intended viewing size.
Read the reading version with no narration. Repair and recheck before
calling any output ready.
```
