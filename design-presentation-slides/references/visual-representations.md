# Visual representations

Choose the form for what the audience must do with the content: compare, look up, trace, locate or read.

| Form | Preserve and check |
| --- | --- |
| Chart | The comparison that matters, with units, denominator, baseline, uncertainty and source. Use common scales across panels that are compared. Show missing data as missing, never as zero. Aligned positions or lengths suit comparing magnitudes. |
| Table | Exact values or common criteria. Align numbers and units; mark missing values, estimates and targets. Keep it a table when exact values are the point. |
| Diagram | The structure of the relationships and what each connection means. Arrows distinguish flow, dependency, control and time. Tie each detail to its place in the whole with labels or connectors as well as colour. |
| Screenshot | The relevant control or result, enough surrounding interface to locate it, and any state that affects the result. Never fabricate controls or alter what the screenshot shows. |
| Quotation | The exact words, the attribution and any qualification that changes the meaning. Mark paraphrase as paraphrase. Allow reading time. |
| Code or equation | The lines or terms the inference needs, with their definitions, assumptions and dependencies. Supply the full material separately when the audience will need it. |
| Image | An object, situation or mood the slide needs. Make clear whether an image is documentary evidence, illustration or generated. One pictured case does not show what is typical. |
| Text | Questions, definitions, exact wording or short reasoning, when a visual would add nothing. |

- When the audience must compare alternatives, keep them on screen together.
- When a gain in one part could be mistaken for a gain in the whole, show the total.
- When a slide shows a system and closeups, keep both visible and match each closeup to its place with labels or connectors as well as colour.

## Cutting and fitting

For each element, ask what becomes harder or less accurate without it. Reorganise before you delete necessary evidence. If needed content is still unreadable, change the scale, split the sequence or move it to supporting material.

Then test the slide: can a fresh viewer locate, compare or trace what it asks of them?
