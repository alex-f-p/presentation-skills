# Editorial rules

These rules apply to everything the audience will see. Only an explicit user instruction, or a template the user requires, overrides one. Applying a rule must never cost accuracy, accessibility, useful detail or the speaker’s voice.

They bind what you write. In material the user wrote, report a banned pattern as a finding and change it only if the request covers that.

The banned patterns are the habits of generated decks, so expect them in your own first draft. Check the draft against every table before you deliver it.

## Writing

Follow William Zinsser’s four principles:

- **Clarity:** Make the point and the sequence easy to follow.
- **Simplicity:** Use plain, precise words, concrete subjects and active verbs.
- **Brevity:** Cut what does no work. Keep needed context and qualifications. There is no word limit, and a sparse slide is not the goal.
- **Humanity:** Sound like the speaker. Keep their humour, warmth and distinctive design; never impose a canned conversational tone.

## Titles

Title a slide with its content in plain words: the finding, the question or the name of the thing shown.

| Never | Looks like | Instead |
| --- | --- | --- |
| Tacked-on afterthought | “Onboarding, reimagined”; “Pricing — simplified” | Put the claim in the title: “Onboarding now takes two steps”. |
| Two-beat contrast | “Same team. Different results.”; “Not a tool. A teammate.” | Write one ordinary sentence with the specifics: “The same team now ships weekly”; “The assistant drafts replies for staff to approve”. Changing the punctuation does not fix it. |
| Manufactured punch | “The numbers don’t lie”; “Enter: automation” | Give the precise fact: “Churn fell from 8% to 5%”. |
| Planning label as heading | “The hook”; “The problem”; “Why this matters” | Name the subject: “Approvals take nine days”. |

## Labels and furniture

Label each thing once.

| Never add | Looks like |
| --- | --- |
| An eyebrow or kicker above the title | “OVERVIEW”; “02 · STRATEGY” |
| A subtitle or intro line that restates the title | “Three regions missed target” followed by “An overview of regional performance” |
| A running header that only names the deck | The deck title repeated on every slide |
| A second label for the same thing | A section tag, title and caption that all say “Results” |
| A badge that announces | “KEY INSIGHT”; “PRO TIP”; “NEW” |
| Interface elements as ornament | Window chrome, pulsing dots, chips or toggles around ordinary content |
| Working cues | “[2 min]”; “TODO”; “pause here” |

A company logo or wordmark is fine on every slide. Keep it small and in the same place.

Working cues belong in presenter material. Status the audience needs stays on the slide: “Draft”, “Preliminary”, “Pending approval”, “Not for distribution”. Code and source excerpts shown as content stay as they are.

If slides are numbered, show the current number alone at bottom right. Use another scheme only if requested. Add a total or position (“7 / 20”, “Step 2 of 4”) only where the audience needs it to keep their place.

## Body text

| Never | Looks like | Instead |
| --- | --- | --- |
| Speech written on a live slide | A paragraph the speaker will also say | Move it to speech or supporting material. A reading deck keeps it. |
| Unrelated jobs on one slide | A definition, a chart and next steps together | Give each slide one principal audience task. |
| Example wrapped in commentary | Instructions before it, a fault list and a verdict after it | Show the example and let it make the point. |
| Overexplaining and disclaimers | “It’s important to note that…”; “Results may vary” | Cut them. Keep qualifiers that change the meaning: “proposed”, “target”. |
| Mannered prose | “A tapestry of insights”; “Where vision meets execution” | State it directly. Use a metaphor only when it makes the point easier to grasp. |

## Emphasis and layout

Decide what the audience should read first and emphasise only that.

| Never | Looks like | Instead |
| --- | --- | --- |
| Competing emphasis | Bold, colour, large type and a closing tagline on one slide | Keep one hierarchy. |
| Marks with no job | Lines, accent strokes or coloured words that mean nothing | Give each a job, such as grouping, separating or marking the key value, or remove it. |
| Forced card grid | Matching cards that hold unlike content | Use matching cards only for comparable items. |

Density follows the task: a comparison may need everything visible at once, a sequence one step at a time. Never assume a density norm from the audience’s culture.

A slide can follow every rule and still fail. Check that the audience can do what the slide asks of them.
